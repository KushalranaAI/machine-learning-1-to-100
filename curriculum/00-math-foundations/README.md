Machine-learning algorithms are not magic - they are a handful of mathematical ideas used over and over:

| Idea | Where it shows up |
|------|-------------------|
| **Vectors & matrices** | every dataset is a matrix $X \in \mathbb{R}^{n \times d}$; every linear model is $Xw$ |
| **Derivatives & gradients** | training = following $-\nabla L$ downhill (regression, logistic, neural nets, boosting) |
| **Probability** | naive Bayes, logistic regression, Gaussian mixtures, evaluation, uncertainty |
| **Optimisation** | gradient descent, Newton's method, coordinate descent, EM |

You don't need to master these before starting - each lesson links back here when it uses an idea.
